## Part 1 - POE (Portfolio of Evidence)

A console-based Java application that allows users to register with a username, password, and South African cell phone number, then login using their credentials.

- **User Registration** - Create an account with username, password, and SA cell phone number
- **Username Validation** - Must contain an underscore (`_`) and be no more than 5 characters
- **Password Validation** - Must be at least 8 characters, contain a capital letter, a number, and a special character
- **Cell Phone Validation** - Must contain the international code (+27) followed by 9 digits (uses Regular Expressions)
- **User Login** - Verify username and password match stored credentials
- **Console-Based** - No GUI, no JOptionPane (as per assignment requirements)
- **Unit Tests** - 14 JUnit tests covering all validation methods
